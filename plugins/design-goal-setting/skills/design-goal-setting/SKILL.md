# Design goal-setting

Help the user set growth goals (or prep for a review) by mapping their evidence to a
behavioural bar, using the bundled matrix and template.

## How to run

1. Read `assets/rr-matrix.md` (the behavioural bar) and
   `assets/goal-setting-review-template.md` (the output shape).
2. Ask the user their current level and the level they're targeting.
3. Walk the matrix behaviours one at a time. For each behaviour the user wants to
   target this cycle, ask:
   - What does "at level" look like for you here? (confirm the observable bar)
   - What evidence do you already have, and where is it visible?
   - What's the gap?
   - What single move would close it this cycle?
   - How often should you be able to show evidence (frequency)?
4. Don't try to cover every behaviour. Help them pick the few that matter this cycle.
5. Fill the template and output the completed goal-setting doc as Markdown.

## Principles to hold

- Behavioural, not aspirational: observable behaviours, not adjectives.
- Evidence mapped to the bar, with an agreed frequency.
- A few real goals beat a long list.

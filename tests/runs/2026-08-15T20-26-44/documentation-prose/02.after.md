# Deploy Runbook

## Preconditions

Deploys run from the `main` branch only. No other branch is deployable.

The build step requires the `SENTRY_AUTH_TOKEN` environment variable.

**Friday freeze:** no deploy happens on a Friday after 15:00 UTC.

## Procedure

1. Run `npm run build`.
2. Check that the build output is under 4 MB.
3. Run `wrangler deploy --env production`.
4. Confirm that `/healthz` returns 200 within 60 seconds.

## If the health check fails

1. Run `wrangler rollback --env production`.
2. Notify the on-call engineer in the **eng-oncall** channel.

```js
/**
 * Resolves the absolute path of the image named in the frontmatter.
 *
 * @param {string} frontmatterName - The image filename as written in the
 *   frontmatter.
 * @param {string} directory - Absolute path to the directory that holds the
 *   images for the post. The caller resolves this before the call.
 * @returns {string} The absolute path to the named image.
 * @throws If no file matching `frontmatterName` exists in `directory`.
 *
 * An earlier version listed the directory and used the first entry. That
 * version imported the wrong image whenever a directory held more than one.
 * Matching on the frontmatter name corrects that. The throw is deliberate for
 * the same reason. A silent fallback imported the wrong image and reported
 * nothing, so a missing file raises an error instead.
 */
```

# shipcheck

`shipcheck` runs before a push. It runs a short list of checks against the working tree and exits non-zero if any of them fail, so the hook stops a failing push instead of review stopping it.

## Install

```
npm install -g shipcheck
```

## Usage

Run `shipcheck` from the root of a repository:

```
shipcheck
```

`shipcheck` reads `shipcheck.json` from the current directory. It runs the checks listed there. It exits non-zero if any of them fail. A clean run exits zero and can be used in a hook.

To print the checks that would fail without acting on them:

```
shipcheck --dry-run
```

`--dry-run` changes nothing. It prints the checks that would fail and then stops. It is useful for testing a new `shipcheck.json`, or for debugging a hook that runs when it is not expected to.

## Checks

| Check | Fails when |
|---|---|
| Uncommitted changes | The working tree has uncommitted changes. |
| TODO in staged files | A staged file contains a `TODO`. |
| Branch is not default | The current branch is the repository's default branch. |

`shipcheck.json` controls which of these checks run.

## Use in a pre-push hook

This is the intended use. Add it to `.git/hooks/pre-push`:

```sh
#!/bin/sh
shipcheck
```

Because `shipcheck` exits non-zero on failure, the push aborts. `shipcheck` prints the failing checks. Where the hook must be skipped, `git push --no-verify` skips it.

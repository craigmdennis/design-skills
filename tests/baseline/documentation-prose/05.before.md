```js
/**
 * Returns the absolute path of the image named in a post's frontmatter.
 *
 * The name is matched exactly. An earlier version listed the directory and
 * took the first file, which resolved to the wrong image whenever the
 * directory held more than one.
 *
 * A missing file is an error, not a fallback. The silent fallback to the
 * first file is what imported the wrong image.
 *
 * @param {string} frontmatterName Image filename as written in the frontmatter.
 * @param {string} directory Directory holding the image. The caller passes an
 *   absolute path.
 * @returns {string} Absolute path of the named image.
 * @throws {Error} When the named file is not present in the directory.
 */
```

Two notes on choices made:

- The rationale for throwing sits in the comment because the behaviour looks unhelpful without it. A reader who does not know the wrong-image error would be tempted to reinstate the fallback.
- The absolute-path requirement is recorded on the `directory` parameter rather than in the description, so it is read at the point where the value is supplied.

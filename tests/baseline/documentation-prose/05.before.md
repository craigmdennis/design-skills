```js
/**
 * Resolves the absolute path of the image named in a post's frontmatter.
 *
 * @param {string} frontmatterName - The image filename as written in the post's
 *   frontmatter.
 * @param {string} directory - Absolute path to the directory holding the post's
 *   images. Callers are expected to resolve this before calling.
 * @returns {string} The absolute path to the named image.
 * @throws If no file matching `frontmatterName` exists in `directory`.
 *
 * An earlier version listed the directory and took the first entry, which
 * imported the wrong image whenever a directory held more than one. Matching on
 * the frontmatter name fixes that. The throw is deliberate for the same reason:
 * falling back silently is what let the wrong image through unnoticed, so a
 * missing file should fail loudly instead.
 */
```

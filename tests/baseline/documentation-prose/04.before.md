## 2.4.0 — 2026-08-01

### Changed
- The search index now updates one document at a time instead of rebuilding the whole index. Reindexing went from about 90 seconds to about 3 seconds. (Proposed by Aisha Nkemelu; reviewed by Dan Rivera on 2026-07-22.)

### Fixed
- Fixed a crash when opening a document with no title, which threw a null reference error.

### Removed
- Removed the `--verbose` flag. Use `--log-level debug` instead.

# Create an export job

```
POST /v1/exports
```

Starts an export job. The job runs asynchronously; the response gives you a URL to poll for its status.

## Authentication

Send a bearer token in the `Authorization` header:

```
Authorization: Bearer <token>
```

## Request body

| Field | Type | Required | Description |
|---|---|---|---|
| `format` | string | Yes | Output format. One of `csv`, `json`, or `parquet`. |
| `since` | string | No | RFC 3339 timestamp. Limits the export to records from this time onward. |

```json
{
  "format": "parquet",
  "since": "2026-08-01T00:00:00Z"
}
```

## Response

`202 Accepted` — the job has been queued.

| Field | Type | Description |
|---|---|---|
| `job_id` | string | Identifier for the job. |
| `status_url` | string | URL to poll for job status and, once complete, the download URL. |

```json
{
  "job_id": "exp_9f3c21",
  "status_url": "https://api.example.com/v1/exports/exp_9f3c21"
}
```

## Errors

| Status | Cause |
|---|---|
| `400 Bad Request` | `format` is missing, or is not one of `csv`, `json`, or `parquet`. |
| `429 Too Many Requests` | The caller already has 3 jobs running. Wait for one to finish before starting another. |

## Expiry

Jobs expire 24 hours after creation. The download URL stops working at that point, so retrieve the file before then. To get the data again after expiry, start a new job.

# Contributing

Thanks for your interest in contributing! This guide covers everything you need to get a change merged.

## Getting started

1. Fork the repository.
2. Make your changes on a branch in your fork.
3. Open a pull request against `main`.

## Commit messages

Commits follow the [Conventional Commits](https://www.conventionalcommits.org/) specification — for example:

```
feat: add retry handling to the upload queue
fix: correct off-by-one in pagination offset
docs: clarify installation steps
```

## Tests

Run the test suite with:

```sh
npm test
```

Any new behaviour must come with a test covering it.

## Review and CI

Before a pull request can be merged it needs:

- **One approving review**, and
- **A passing CI run.**

**Exception:** documentation-only changes do not require an approving review. (Decided by Priya Raman on 2026-02-20.) CI must still pass.

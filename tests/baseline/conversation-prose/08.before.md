"Figure" is my shorthand for "figure of speech". I introduced the word and never defined it.

It covers any wording that means something other than its literal sense:

- **Metaphor** — "the seam between two runtimes". There is no seam.
- **Idiom** — "earned its keep". A fixed phrase whose meaning you cannot work out from the words.
- **Figurative phrasal verb** — "dressed it up as", "touched the problem", "went the same way". The class you caught, and the hardest to see, because each one looks like plain English.
- **Personification** — "the check earned", "the parser is happy". An object or an abstract thing given human behaviour.
- **Dead metaphor** — "churn", "lever", "land", "surface" as a verb. The image is worn away, so it reads as ordinary vocabulary.

ASD-STE100 bans all five.

The word itself is also academic register, and `my-voice` bans that when talking about writing. Both skill files use "figure" repeatedly. I can replace it with "metaphors and idioms" throughout if you want the files to read in plain words.
